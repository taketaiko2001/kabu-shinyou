# 買い残減少スクリーナー

信用の買い残が「出来高に比べて重かったのに大きく減った」東証の銘柄を拾い、押し目の買い値・損切り・利確の価格を出すツールです。決算が近い銘柄は、業績の進み具合（進捗率）・市場予想（コンセンサス）との差・決算前の上昇・過去の決算での値動きから、決算で上がるか下がるかも予想に入れます。

- 閲覧ページ：https://taketaiko2001.github.io/kabu-shinyou/
- 更新：平日9:00（寄り付き前・前日終値ベース）と12:30（前引け後・前場の株価ベース）にクラウドの定期ルーティンで自動更新。祝日・年末年始は休み。

**このリポジトリは公開データから機械的に計算した分析で、投資の助言や売買の推奨ではありません。発注は行いません。**

## 考え方（検証の要点）

### 信用残（220銘柄・2025年6月〜2026年7月の週次 12,191件）

| 型 | 件数 | 20日後の対日経 | 勝率 | ルール売買の期待値 |
|---|---|---|---|---|
| 買い残減（−10%以下）× 取組が重い（出来高1日分以上） | 300 | +2.81% | 61% | +1.63%/回 |
| うち 株価下落中に減少（投げ一巡型） | 46 | +8.09% | 74% | +4.58%/回 |
| 買い残減 × 取組が軽い（大型株に多い） | 1,825 | −2.34% | — | +0.53%/回 |

### 決算（189銘柄・1,334回、発表前日→翌営業日の対日経）

- 平均の値幅は±6.0%。
- 決算前20日に日経平均を10%以上上回った銘柄は、決算で上がった割合が42%（中央値−1.5%）。ただしその後20日は+4.0%。
- 前の四半期の経常益が前年比+50%以上なら、上がった割合は56%（+1.5%）。
- 好業績で決算前の上昇が小さい銘柄は56%、好業績でも上げすぎていた銘柄は42%。
- 進捗率とコンセンサスとの差は過去の値が無いため未検証。影響は小さめに設定。

## 売買ルール

- 買い目安：25日線付近（現在値から0.3〜1ATR下）。指値は5営業日有効。
- 損切り：買値−1.5ATR。利確1：+1.5ATRで半分、残りの損切りを買値へ。利確2：+3ATR（手前の高値があればその下）。20営業日で時間切れ。
- 決算：上がる確率60%以上ならまたいでよい、42%以下なら前日までに全部売る、その間は半分以上を売る。

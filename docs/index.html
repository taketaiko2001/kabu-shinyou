仮想売買のルール
  1. 口座：デイトレード・スイング・長期保有に100万円ずつ。口座の間でお金は移さず、増えた分（確定した利益）はその口座で使います。
  2. 期間：デイトレードはその日の大引けで必ず決済。スイングは長くても1か月（期限の日の大引けで決済）。長期保有は期限なし。
  3. 銘柄数：同時に持つのは口座ごとに5銘柄まで。
  4. 注文：売買は成行。注文した時刻より後に始まる最初の1分足の始値で約定とします。株価は15〜20分遅れで届くため、約定の値段は次の更新か大引け後の精算で決まります。
  5. 損切り：逆指値（成行）。株価がラインに触れたら、そのときの値段（ラインより下で始まった足ならその始値）で売ります。デイトレードは朝の窓下げ買いが買値−5%・後場の強い銘柄買いが買値−3%、スイングは計算の損切りラインに置きます。
  6. デイトレードの形：検証で成績のよかった形だけを使います。いまは「朝の窓下げ買い」（寄り付き前の8:30ごろに注文し、寄り付きで買って大引けで売る。日経平均先物が大きく下げている日は休む）と「後場の強い銘柄買い」（12:40ごろ買って大引けで売る）。毎日の大引け後に最新のデータで検証し直し、成績が崩れたら止めたり条件を変えたりします（下の「デイトレードの検証」）。
  7. 確認する時刻：朝8:30ごろ（寄り付き前）・10:07・11:07・12:30・13:37・14:37・15:30に、約定・損切り・利確・新しい買いを確認します。朝・12:30・15:30はAI（Claude）が海外市場・市況ニュース・個別のニュースも見て判断し、10:07・11:07・13:37・14:37は決めたルールどおりにプログラムが確認します。
  8. このページの更新：朝8:45ごろ・12:30すぎ・15:30すぎの3回です。その間の売買は、次の更新でまとめて表示されます（15:30の更新は大引け値を待つので16時ごろ届きます）。
  9. 計算の前提：100株単位・現物のみ。手数料と税金は0円として計算しています。

検証①：買い残の減少は本当に効くのか

売買代金の多い220銘柄について、2025年6月〜2026年7月の週次信用残（12,191件）を使いました。信用残が公表された日の終値で買ったとして、20営業日後に日経平均よりどれだけ上回ったかの平均です。

日経平均より下0日経平均より上
  • 買い残が減っても、それが出来高の1日分に満たない（大型株に多い）なら効果はなく、むしろ日経平均に負けていました。
  • 効いたのは、減る前の買い残が出来高の1日分以上あった銘柄です。株価が下がる中で減った「投げ一巡型」は成績がよい一方、件数が少なく振れ幅は大きいと見てください。
  • 期待値は、下のルールで売買した場合の1回あたりの平均損益です（本命型は値幅ATRの0.35倍、投げ一巡型は0.89倍）。決算をまたぐ場合は、決算予想の分を足しています。

検証②：決算の前後で株価はどう動いたか

条件件数決算での平均中央値上がった割合その後20日
  • 決算前に大きく上げた銘柄は、決算翌日に売られやすい（期待が織り込み済み）。ただしその後20日は上がりやすく、決算後の下げは押し目になりやすい。
  • 直近の業績が強い銘柄は決算でも上がりやすい。業績が強くても決算前に上げすぎていると、逆に下がりやすい。
  • 過去の決算で大きく動いた銘柄ほど、次も大きく動く（相関0.31）。想定の値幅はその銘柄の過去の平均です。
  • 進捗率と市場予想（コンセンサス）との差は、過去の値が手に入らず検証できていません。上がる確率への影響は小さめにしています。

価格の決め方と売買のルール

ATRは「過去14日の平均的な1日の値幅」です。値動きの大きい銘柄ほど、損切りも利確も広くとります。

  1. 買い目安（押し目）：株価が25日線より上なら、25日線と「現在値−1ATR」の高い方。下なら、20日安値の少し上と「現在値−1ATR」の高い方。指値は5営業日有効。届かなければ見送り。
  2. 損切り：買値−1.5ATR。買ったらすぐ逆指値を入れる。
  3. 利確1：買値＋1.5ATRで半分を売る。売ったら残りの損切りを買値まで引き上げる。
  4. 利確2：買値＋3ATR。手前に60日高値や52週高値があるときはその少し下。
  5. 時間切れ：20営業日たっても届かなければ残りも売る。
  6. 決算：カードの「決算予想」の対応に従う。上がる確率が60%以上ならまたいでよい、42%以下なら前日までに全部売る、その間は半分以上を売る。決算の窓開けは逆指値では防げない。
  7. 株数：損切り時の損失が資金の1%程度に収まる株数にする。
  8. AIの見立て：計算結果をAI（Claude）がニュースやデータの欠けと照らして点検した判断です。「買い候補」は計算どおり、「慎重」は株数を減らすか様子を見る、「見送り」は今回は買わない。価格や確率の数字は変えません。
